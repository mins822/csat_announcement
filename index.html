2027학년도 수능 시험장 안내방송 · 타종 타이머

수능 당일 시험장의 예비령, 준비령, 본령, 종료령 타종과 안내방송을 그대로 재현한 무료 웹 타이머입니다. 공식 타종 음원 37개, 3교시 영어 듣기평가 자동 재생, 시험장 백색소음 생성기, 영역별 맞춤 시간표로 집이나 독서실에서도 수능 당일처럼 실전 연습을 할 수 있습니다.

제작자 mins822

주요 기능

  • 수능 타종 37종 — 1~5교시 감독관 입실·예비령·준비령·본령·종료 10분 전·종료 5분 전·종료령 음원 내장
  • 영어 듣기평가 자동 재생 — 3교시 13:07 듣기평가 안내방송 시점에 맞춰 업로드한 듣기평가 음원을 연동 재생
  • 시험장 백색소음 — 시험지 넘김, 준비령 파본검사, 종료 10~5분 전 시험지 검토, 샤프 필기, OMR 마킹 소리를 HRTF 3D 입체음향으로 재현
  • 자리·인원·실력 설정 — 4열×7행 시험장에서 내 자리를 고르고 수험생 수와 실력 수준에 따라 소음 조절
  • 아날로그 수능 시계 — 시험장 벽시계처럼 남은 시간을 한눈에 확인하고 바늘 드래그로 이동
  • 영역별 맞춤 시간표 — 과목별 타종 체크박스 선택, 시간 간격·시각 편집 및 북마크 저장
  • 예약 시작 — 원하는 실제 시각에 시간표가 자동으로 시작
  • 오프라인 사용 — 단일 HTML 파일로 저장하고 친구와 공유

수능 타종 용어 설명

감독관 입실 · 입실 완료
수험생 입실 준비 및 시험실 입실 마감을 알리는 안내 타종입니다.
예비령
답안지 배부 및 수험생 유의사항 안내 등 시험 시작이 가까워졌음을 알리는 타종입니다.
준비령
문제지를 배부하고 인쇄 상태를 확인하는 파본검사를 진행하도록 알리는 타종입니다.
본령 · 듣기평가 안내방송
시험이 시작되는 타종입니다. 3교시 영어 영역은 13:07 듣기평가 안내방송에 이어 별도 본령 타종 없이 듣기평가가 시작됩니다.
종료 10분 전 · 종료 5분 전
남은 시간을 알려 주는 타종입니다. 1·2·3·5교시는 종료 10분 전에, 4교시 한국사·탐구 영역은 종료 5분 전에 울립니다.
종료령
시험 종료 및 답안지·문제지 회수를 알리는 타종입니다.

시험장 백색소음 모드

실전에서 가장 낯선 것은 의외로 소리입니다. 옆 사람이 시험지를 넘기는 소리, 준비령 파본검사 때 종이를 확인하는 소리, 종료 10분 전~5분 전 시험지를 검토하며 페이지를 넘기는 소리, 샤프로 필기하는 소리, OMR 카드에 마킹하는 소리를 HRTF 3D 입체음향으로 방향감 있게 재현합니다. 과목별 시간 흐름에 따라 소리가 달라지고, 4열×7행 좌석 위치와 수험생 인원·실력 수준을 바꿔 가며 연습 환경을 조절할 수 있습니다.

이런 때 사용하세요

  • 수능 D-day 전 시간 배분과 타종 적응 연습
  • 평가원 모의평가·사설 모의고사를 실전처럼 풀 때
  • 독서실·집에서 시험장 소음 속 집중력 훈련
  • 영어 듣기평가 시작 시각(13:07)에 맞춘 실전 루틴 점검
  • 학교·학원·스터디에서 모의고사 안내방송이 필요할 때

자주 묻는 질문

수능 타종은 어떤 순서로 울리나요?

교시마다 감독관 입실, 예비령, 준비령(파본검사), 본령, 종료 전 안내(1·2·3·5교시는 종료 10분 전, 4교시 한국사·탐구는 종료 5분 전), 종료령 순서로 울립니다. 이 사이트는 1~5교시 전체 타종 37개 음원을 시간표에 맞춰 재생합니다.

영어 듣기평가도 재생되나요?

네. 3교시 영어 영역의 13:07 듣기평가 안내방송 시점에 맞춰 업로드한 듣기평가 음원이 자동으로 연동 재생됩니다.

시험장 백색소음 모드는 무엇인가요?

시험지 넘기는 소리, 준비령 파본검사 소리, 샤프 필기 소리, OMR 답안 마킹 소리를 HRTF 3D 입체음향으로 재생해 실제 시험장과 비슷한 환경에서 연습할 수 있는 기능입니다. 자리(4열×7행)와 수험생 인원, 실력 수준을 설정할 수 있으며 마지막 켜짐/꺼짐 상태가 자동 유지됩니다.

원하는 시각에 맞춰 시작할 수 있나요?

네. 실제 시각 예약 시작 기능으로 원하는 시각에 시간표가 시작되도록 설정할 수 있습니다.

인터넷 없이도 사용할 수 있나요?

오프라인용 단일 HTML 파일로 저장해 공유하고 사용할 수 있습니다.
