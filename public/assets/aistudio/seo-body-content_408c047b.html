2027학년도 수능 시험장 안내방송 · 타종 타이머

수능 당일 시험장의 예비령, 준비령, 본령, 종료령 타종과 안내방송을 그대로 재현한 무료 웹 타이머입니다. 공식 타종 음원 37개, 3교시 영어 듣기평가 자동 재생, 시험장 백색소음 생성기, 영역별 맞춤 시간표로 집이나 독서실에서도 수능 당일처럼 실전 연습을 할 수 있습니다.

제작자 mins822 · 개인이 만든 비공식 연습용 도구이며 한국교육과정평가원·교육부와 관련이 없습니다.

주요 기능

  • 수능 타종 37종 — 1~5교시 예비령·준비령·본령·종료 10분 전·종료 5분 전·종료령 음원 내장
  • 영어 듣기평가 자동 재생 — 3교시 시작 시점에 맞춰 안내방송과 듣기평가를 연동
  • 시험장 백색소음 — 시험지 넘김, 파본검사, 샤프 필기, OMR 마킹 소리를 HRTF 3D 입체음향으로 재현
  • 자리·인원·실력 설정 — 4열×7행 시험장에서 내 자리를 고르고 수험생 수와 실력 수준에 따라 소음 조절
  • 아날로그 수능 시계 — 시험장 벽시계처럼 남은 시간을 한눈에 확인
  • 영역별 맞춤 시간표 — 과목별 타종 설정과 시간 간격 편집
  • 예약 시작 — 원하는 실제 시각에 시간표가 자동으로 시작
  • 오프라인 사용 — 단일 HTML 파일로 저장하고 친구와 공유

시험장 백색소음 모드

실전에서 가장 낯선 것은 의외로 소리입니다. 옆 사람이 시험지를 넘기는 소리, 파본검사 때 종이를 확인하는 소리, 샤프로 필기하는 소리, OMR 카드에 마킹하는 소리를 HRTF 3D 입체음향으로 방향감 있게 재현합니다. 과목별 시간 흐름에 따라 소리가 달라지고, 수험생 인원과 실력 수준을 바꿔 가며 연습 환경을 조절할 수 있습니다.

이런 때 사용하세요

  • 수능 D-day 전 시간 배분과 타종 적응 연습
  • 평가원 모의평가·사설 모의고사를 실전처럼 풀 때
  • 독서실·집에서 시험장 소음 속 집중력 훈련
  • 영어 듣기평가 시작 시각(13:07)에 맞춘 실전 루틴 점검
  • 학교·학원·스터디에서 모의고사 안내방송이 필요할 때

자주 묻는 질문

수능 타종은 어떤 순서로 울리나요?

교시마다 예비령, 준비령(파본검사), 본령, 종료 10분 전, 종료 5분 전, 종료령 순서로 울립니다. 이 사이트는 1~5교시 전체 타종 37개 음원을 시간표에 맞춰 재생합니다.

영어 듣기평가도 재생되나요?

네. 3교시 영어 영역의 13:07 듣기평가 안내방송 시점에 맞춰 듣기평가가 자동으로 연동 재생됩니다.

시험장 백색소음 모드는 무엇인가요?

시험지 넘기는 소리, 파본검사 소리, 샤프 필기 소리, OMR 답안 마킹 소리를 HRTF 3D 입체음향으로 무작위 재생해 실제 시험장과 비슷한 환경에서 연습할 수 있는 기능입니다. 자리(4열×7행)와 수험생 인원, 실력 수준을 설정할 수 있습니다.

원하는 시각에 맞춰 시작할 수 있나요?

네. 실제 시각 예약 시작 기능으로 원하는 시각에 시간표가 시작되도록 설정할 수 있습니다.

인터넷 없이도 사용할 수 있나요?

오프라인용 단일 HTML 파일로 저장해 공유하고 사용할 수 있습니다.

공식 사이트인가요?

아닙니다. 개인 제작자 mins822가 만든 비공식 실전 연습용 도구이며, 한국교육과정평가원 및 교육부와 관련이 없습니다. 실제 시험 시각과 안내는 반드시 공식 공지를 확인하세요.
