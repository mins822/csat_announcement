이번 개선의 핵심

이전 버전처럼 버튼 안에 배경 캡처 이미지를 덧씌우지 않는다. 실제 배경을 backdrop-filter가 직접 처리하고, SVG 변위 맵은 가장자리의 얕은 렌즈 효과에만 사용한다. 블러는 0.8px, 표면 틴트는 약 2~2.5% 수준으로 낮췄다. 굴절 필터를 지원하지 않는 브라우저에서는 낮은 블러와 반사 경계로 대체한다.

Note — 웹 렌더링으로 재현한 시각적 근사이며 네이티브 iOS 렌더러와 동일하지 않다.HTML · CSS · SVG Filter · JavaScript
